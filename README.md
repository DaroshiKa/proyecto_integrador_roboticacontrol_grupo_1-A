# Proyecto integrador: Robótica y Control Digital


## Áreas de trabajo

- **[Robótica](https://github.com/DaroshiKa/proyecto_integrador_roboticacontrol_grupo_1-A/tree/robotica)** — firmware del manipulador SCARA y avances por entrega. La entrega 2 se encuentra en `avances/entrega2/`.
- **[Control digital](https://github.com/DaroshiKa/proyecto_integrador_roboticacontrol_grupo_1-A/tree/control-digital)** — modelos, simulaciones, análisis y documentación correspondientes a control digital.

## Organización

Cada área mantiene sus avances en su propia rama para evitar mezclar cambios que pertenecen a asignaturas distintas.
